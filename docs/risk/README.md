# Phase 26 — Advanced Quantitative Risk & Stress Testing Engine OS

## Overview

The **Advanced Quantitative Risk & Stress Testing Engine OS** is a research-grade quantitative risk analysis framework built for the Multi-Modal Quant AI platform. It evaluates portfolio and strategy risk across normal market conditions, historical stress events, hypothetical shock scenarios, Monte Carlo simulations, liquidity stress, and transaction cost shocks.

> [!IMPORTANT]
> **RESEARCH ONLY & STRICT NO-LIVE-TRADING SAFETY**:
> All risk analytics, stress test outputs, Monte Carlo simulations, and limit breach alerts generated by this engine are strictly for research, simulation, and risk diagnostics. The engine does **NOT** execute automatic buy/sell orders or initiate live trading.

### 1. Market & Portfolio Risk Diagnostics
- **Volatility**: Historical, Rolling, EWMA.
- **Beta**: Asset & Portfolio beta relative to configurable benchmarks.
- **Correlation & Covariance**: Matrix audit, condition number, positive semi-definiteness, structural shift detection.
- **Factor Exposure**: Market, Size, Value, Momentum, Volatility, Quality.
- **Risk Attribution**: Marginal Contribution to Risk (MCR), Component Contribution to Risk (CCR), Percentage Contribution to Risk (PCR). Guaranteed numerical reconciliation ($\sum \text{CCR}_i = \sigma_p$).
- **Concentration**: HHI, Effective Number of Assets ($N_{\text{eff}}$), Top 5/10 position weights.

### 2. Tail Risk & Drawdown Analytics
- **VaR Engine**: Historical quantile, Parametric Gaussian/t-dist, Monte Carlo simulation.
- **CVaR Engine**: Tail loss expectation (Expected Shortfall).
- **Drawdown Analyzer**: Peak-to-trough events, maximum drawdown depth, recovery duration.

### 3. Scenario & Stress Testing Engine
- **Scenario Registry**: Versioned scenario loader (`historical_stress.yaml`, `hypothetical_stress.yaml`, `liquidity_stress.yaml`).
- **Historical Stress Engine**: Applies exact historical asset returns (e.g. 2008 Financial Crisis, 2020 COVID shock).
- **Hypothetical Stress Engine**: Multi-asset equity shocks, volatility multipliers, correlation collapses, interest rate shifts.
- **Liquidity & Cost Stress**: ADV capacity, bid-ask spread widening, slippage multipliers, transaction cost stress.

### 4. Monte Carlo Risk Engine
- Correlated multivariate returns generation via Cholesky decomposition.
- Configurable random seed (`seed=42`) for 100% reproducible P&L distributions.
- Large simulation vectors saved to disk artifacts (`artifacts/risk/monte_carlo/`).

### 5. Risk Limits & Breach Alerts
- Evaluates max VaR, max CVaR, max Drawdown, gross leverage, and concentration thresholds.
- Emits `RISK_LIMIT_BREACH` diagnostic alerts without executing trades.

## API Endpoints

- `POST /api/v1/risk/run` — Compute full risk snapshot for a portfolio.
- `GET /api/v1/risk/{id}` — Fetch risk snapshot.
- `GET /api/v1/risk/{id}/var` — Retrieve VaR analysis (Historical, Parametric, Monte Carlo).
- `GET /api/v1/risk/{id}/cvar` — Retrieve CVaR / Expected Shortfall metrics.
- `GET /api/v1/risk/{id}/drawdown` — Retrieve drawdown metrics & peak-to-trough events.
- `GET /api/v1/risk/{id}/contributions` — Retrieve asset risk contributions and HHI concentration.
- `POST /api/v1/risk/{id}/stress` — Execute historical/hypothetical/liquidity stress tests.
- `POST /api/v1/risk/{id}/monte-carlo` — Execute Monte Carlo simulation.
- `GET /api/v1/risk/{id}/limits` — Audit portfolio against configured risk limits.
- `GET /api/v1/risk/{id}/report` — Generate comprehensive Markdown risk report.
- `GET /api/v1/risk/health` — Risk Engine OS healthcheck.

## Command Line Interface (CLI)

```bash
# Run full risk snapshot
python risk/cli/run.py --portfolio PORT_001

# Calculate VaR / CVaR
python risk/cli/var.py --portfolio PORT_001 --confidence 0.95

# Run stress tests
python risk/cli/stress.py --portfolio PORT_001 --scenario market_crash_2008

# Run Monte Carlo simulation
python risk/cli/monte_carlo.py --portfolio PORT_001 --simulations 10000 --seed 42

# Generate markdown report
python risk/cli/report.py --portfolio PORT_001
```
