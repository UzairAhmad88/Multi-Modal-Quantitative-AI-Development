# Portfolio Summary: Multi-Modal Quant AI Platform

## Short Summary (GitHub / CV)
A research-grade quantitative AI research platform engineered in Python, PyTorch, XGBoost, FastAPI, PostgreSQL, Supabase, and Docker. Implements multi-modal deep learning feature fusion across daily market prices, FinBERT news sentiment, and quarterly SEC financial statements. Features point-in-time data leakage protection, risk-gated portfolio optimization (max asset 25%, max sector 40%), event-driven backtesting with transaction costs, walk-forward cross-validation, and an institutional dark-theme Web OS research terminal.
